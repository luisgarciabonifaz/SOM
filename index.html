    Sistemas Operativos Monopuesto¶

    Bienvenido/a a los apuntes del módulo Sistemas Operativos Monopuesto del Ciclo Formativo de Grado Medio en Sistemas Microinformáticos y Redes.

    Duración y organización¶

    Ficha del módulo

    • Duración total: 120 horas · 3 evaluaciones
    • Distribución: 36h · 42h · 42h (véase Evaluación y horas)
    • Metodología: Eminentemente práctica, basada en el proyecto TechPyme S.L.
    • Resultados de aprendizaje: RA1 a RA5 (véanse más abajo)
    • Sistema de evaluación detallado: véase Evaluación y horas

    Resultados de aprendizaje¶

    1. Reconoce las características de los sistemas de archivo, describiendo sus tipos y aplicaciones.
    2. Instala sistemas operativos, relacionando sus características con el hardware del equipo y el software de aplicación.
    3. Realiza tareas básicas de configuración de sistemas operativos, interpretando requerimientos y describiendo los procedimientos seguidos.
    4. Realiza operaciones básicas de administración de sistemas operativos, interpretando requerimientos y optimizando el sistema para su uso.
    5. Crea máquinas virtuales identificando su campo de aplicación e instalando software específico.

    Proyecto conductor: TechPyme¶

    A lo largo de todo el curso trabajaremos sobre un caso práctico: la infraestructura informática de TechPyme S.L., una pequeña empresa con equipos Windows y Linux que comparten información entre sí a través de un servidor de ficheros.

    Conoce el proyecto TechPyme

    Cómo usar estos apuntes

    Cada unidad incluye teoría, ejemplos y un bloque final de prácticas, muchas de ellas vinculadas al proyecto TechPyme. Se recomienda tener siempre a mano una máquina virtual para ir probando los conceptos según se explican.
