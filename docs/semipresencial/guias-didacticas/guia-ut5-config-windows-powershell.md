# UT5 — Configuración básica de Windows e introducción a PowerShell

!!! info "Duración"
    **Desde:** 11 de enero de 2027
    **Hasta:** 31 de enero de 2027
    **Duración estimada:** 3 semanas (14h)

## Contenido

Esta unidad combina dos bloques. En el primero se realiza la configuración básica de Windows tras la instalación: configuración de red, fecha/hora, gestor de dispositivos, actualizaciones, y personalización del sistema. En el segundo bloque se presenta **PowerShell**, la herramienta de línea de comandos que usaremos de forma exclusiva a lo largo de todo el módulo para las tareas de administración de Windows (no se trabajará con el símbolo del sistema CMD).

La introducción a PowerShell cubre la sintaxis de cmdlets (verbo-sustantivo), el uso del pipeline para encadenar comandos, la obtención de ayuda (`Get-Help`), y los primeros cmdlets de consulta del sistema. Esta base es imprescindible para la administración de usuarios y permisos que se trabajará en UT6.

## Acciones

En casa, realiza la configuración básica indicada sobre tu VM-WIN y completa los ejercicios de PowerShell propuestos, practicando la sintaxis de cmdlets y el uso del pipeline. Es recomendable ir anotando los comandos utilizados, ya que servirán de referencia para la unidad siguiente; aprovecha la sesión presencial semanal para resolver dudas de sintaxis.
