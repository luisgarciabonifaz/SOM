# Guias Diadacticas (Semipreencial)

Estas son las guias didacticas para los alumnos de semipresencial de cada uno de los temas.

!!! tip "Modalidad semipresencial"
    Cada semana hay **una única sesión presencial voluntaria de 1 hora**. En ella se resumen los contenidos clave de la semana y se resuelven dudas sobre la documentación y las actividades, que el alumnado debe haber trabajado previamente en casa.
    
    Para el alumnado que no pueda asistir a las tutorias colectivas puede solicitar mediante cita previa una tutoria individual.
