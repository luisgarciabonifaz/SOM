# Sesiones de 2 horas

El módulo (120 h) se divide en **60 sesiones de 2 horas**, repartidas según las horas que el [calendario](calendario.md) asigna a cada unidad. Los exámenes de evaluación no están incluidos.

| Unidad | Sesión | Contenido |
|---|---|---|

| UT1 | 2 | 1.1 Clasificación, componentes y panorama de SO actuales |
| UT1 | 3 | 1.2 Dispositivos de almacenamiento, estructura física (HDD) y lógica (particiones) |
| UT1 | 4 | 1.2 MBR vs GPT, BIOS/Legacy vs UEFI |
| UT1 | 5 | 1.3 Sistemas de archivos: Windows, Linux, journaling, comparativa y cuál elegir |

| UT2. Hardware y requisitos de instalación | 1 | 2.1 Hardware desde el punto de vista del SO: componentes, 32 vs 64 bits, drivers |
| UT2 | 2 | 2.2 Requisitos mínimos y recomendados, compatibilidad, VT-x / AMD-V |
| UT2 | 3 | 2.3 Medios de instalación: tipos, ISO, medios booteables, verificación de integridad |
| UT2 | 4 | 2.4 Planificación de una instalación: tipos, decisiones previas, checklist |
| UT2 | 5 | 2.5 Prácticas de la unidad |
