# 2ª Evaluación: Windows

En esta evaluación instalamos, configuramos y administramos **Windows**, aplicándolo íntegramente sobre **VM-WIN**, la máquina virtual Windows de TechPyme.

## Unidades de trabajo

| Unidad | Título | RA |
|---|---|---|
| UT4 | Instalación de Windows | RA2 |
| UT5 | Configuración básica de Windows (+ introducción a PowerShell) | RA3 |
| UT6 | Administración de Windows (permisos NTFS en profundidad) | RA4 |

!!! info "PowerShell como herramienta principal"
    A partir de esta evaluación, todas las tareas de línea de comandos en Windows se realizan con **PowerShell**, en lugar del símbolo del sistema (CMD) clásico. La UT5 incluye una introducción a PowerShell antes de usarlo en el resto del bloque.

## Hito del proyecto TechPyme

Al finalizar esta evaluación, **VM-WIN** estará completamente instalada, configurada y administrada: con los usuarios y grupos de **Dirección, Compras y Ventas**, permisos NTFS diferenciados entre departamentos, y una carpeta compartida en red accesible desde el equipo físico del alumno.

!!! example "Entregable de la evaluación"
    VM-WIN operativa, con snapshot final "VM-WIN completa", y un documento con la matriz de permisos NTFS y de recurso compartido de cada carpeta de departamento.
